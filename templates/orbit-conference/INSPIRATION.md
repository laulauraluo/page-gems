# Orbit — design notes

Reference: [GitHub Universe homepage](https://githubuniverse.com/), observed October 14, 2026. The reference is the event homepage, not its speakers directory.

Retained visual ideas: a giant single-line wordmark; pale gray-green background; black text with a vivid green accent; monospace metadata; thin grid borders; split introductory panels; generous, editorial section spacing.

Independent work: all HTML, CSS and JavaScript, the Orbit identity, fictional event content, and the inline geometric orbital SVG. No reference source, GitHub logo, speaker portrait, partner mark, or testimonial is included. The price and program are explicitly illustrative, not claims about a real event.

The source screenshot informed the visual direction. This template does not claim pixel-perfect reproduction or implement the reference site's private registration flow. It has no affiliation with GitHub.
